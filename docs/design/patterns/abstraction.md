# Abstraction and composition

Definition revisions follow the index registry. Every row inherits [the library interface](../pattern-library.md), slot rules, annotation, checks, and maturity.

| ID and purpose | Behavior slots | Semantics and failures | Children/context | Filled instance and expected result | Incomplete instance and expected finding | Specific checks |

| ABS-INTERFACE: declare and bind abstract responsibilities | R `operations:Map<Name,OperationSignature>[1..n]`, `mode:enum(abstract,concrete)`. C(mode=concrete) `bindings:Map<Name,Ref<Operation>>[1..n]`. | Abstract mode exposes declared extension points and is not an executable target. Concrete mode binds every operation and preserves its admitted inputs, guarantees, effects and termination. Missing bindings block concrete use. Dispatch selects the binding named by the interface member. | definitions 1..n, no evaluation order until invocation. Only declared interface members are visible. Finding `missing-required`, path bindings. | N resolves members. C checks substitution and complete concrete binding. |
| ABS-GENERIC: instantiate parameterized meaning | R `parameters:Map<Name,Constraint>[1..n]`, `arguments:Map<Name,Ref<Type>>[1..n]`, `body:Ref<Definition>`, `dispatch:enum(static,tagged-dynamic)`. C(dispatch=tagged-dynamic) `tags:Map<Name,Ref<Type>>[1..n]`. | Substitute each named type argument only after its constraint holds. Static dispatch uses the selected definition. Tagged dynamic dispatch selects one declared tag and preserves the same interface. Unsupported constraint proof remains indeterminate. Instantiation terminates for a finite acyclic expansion or declared recursion bound. | body 1 definition. Type parameters visible only inside it. No runtime exit or effect from instantiation. Type/module. | parameters={T:equality-defined}, arguments={T:Int}, body=identity<T>, dispatch=static. Produces Int identity signature. | Remove arguments.T. Finding `missing-required`, path arguments.T. | T checks arity/constraints. C checks substitution and recursive expansion. P checks profile instantiation/dispatch differences. |
| ABS-INHERIT: derive at declared extension points | R `base:Ref<Contract>`, `inherited:Set<Ref<Clause>>[1..n]`, `extensions:Map<Name,OperationSignature>[0..n]`, `overrides:Map<Name,Ref<Operation>>[0..n]`, `conflict:enum(reject-unresolved)`. | Preserve every inherited guarantee for every base-admitted input. Override only declared extension points. Conflicting inherited clauses block concrete acceptance. Termination and effects cannot weaken inherited promises. Inheritance itself changes no runtime state. | Override definitions 0..n, named base points only. No implicit member visibility. Contract/module/type. | base=IdentityBase@r1, inherited={identity guarantee}, extensions={apply:Int→Int identity}, overrides={apply:Id}, conflict=reject-unresolved. Identity guarantee remains. | Change override to operation accepting only positive Int. Finding `substitution-conflict`, path overrides.apply.requires. | C checks input widening/result strengthening, conflicts, extension legality and dependency revisions. |
| ABS-COMPOSE: connect typed operations | R `parts:List<Ref<PatternInstance>>[1..n]`, `edges:Set<Ref<Relation>>[0..n]`, `exposed:OperationSignature`, `failure:enum(propagate,handle)`. C(failure=handle) `handler:Op`. | Execute only through explicit order, argument/result, effect and failure relations. Combined guarantees include every edge obligation. Empty edges is valid only for one self-contained part. Handler consumes only declared failures. Terminates when reachable operations and edge cycles satisfy explicit progress/bounds. | parts 1..n with order supplied by edges. Visibility crosses only explicit binds. Exits use explicit invocation targets. Operation/contract. | parts=[Id], edges=[], exposed=Int→Int identity pure total, failure=propagate. Input 2 returns 2. | parts=[Id,Id], edges=[], with no mapping/order. Finding `missing-composition-edge`, path edges. | C derives edge obligations, order, result flow, failures, effects, lifetime and cycles. |

IdentityBase is a fixture contract admitting every mathematical Int and guaranteeing unchanged output, no effects, and finite return.

Generic Constraint is a declared predicate over type capabilities. It is not an unchecked text assertion.
