# Values and types

Definition revisions follow the index registry. Every row inherits [the library interface](../pattern-library.md), slot rules, annotation, checks, and maturity.

Context: type or expression. These entries have no operation children, external effects, or nonlocal exits. Value construction terminates for finite inputs.

| ID and purpose | Behavior slots | Semantics and failures | Children/context | Filled instance and expected result | Incomplete instance and expected finding | Specific checks |
| --- | --- | --- | --- | --- | --- | --- |
| VAL-LITERAL: admit one value | R `type:Ref<Type>`, `value:TypedValue`. C(machine-bounded numeric type) `overflow:enum(reject,wrap,saturate)`. | Value satisfies the exact type, unit, range, and precision. Construction outside the domain rejects. No implicit numeric conversion. | None. Expression or type. | type=Int[0..3], value=Known 0. Result is integer zero. overflow is not applicable to this mathematical type. | Remove type. Finding `missing-required`, path type. Value 0 supplies no inferred type. | T checks domain/unit/precision and conditional overflow. P checks later language compatibility. |
| VAL-RECORD: construct named fields | R `type:Ref<RecordType>`, `fields:Map<Name,Binding>`. C(type permits extras) `extraType:Ref<Type>`. | Each field uses its declared requiredness, type, absence, and empty rules. Unknown fields reject unless extras are explicitly typed. | Field expressions: exactly one per supplied field, declaration order, visible earlier fields only if declared, no exits. Expression/type. | type=Pair{left:Int,right:Int}, extras=reject, fields={left:1,right:2}. Result is Pair(1,2). | Remove right. Finding `missing-required`, path fields.right. left remains valid. | S/T validate field coverage. C checks field evaluation dependencies. |
| VAL-COLLECTION: construct finite ordered or unique values | R `kind:enum(sequence,set)`, `elementType:Ref<Type>`, `items:List<TypedValue>[0..n]`, `minimum:Nat`, `maximum:Nat`, `equality:Predicate`. C(kind=set) `duplicates:enum(reject,coalesce)`. C(kind=sequence) `order:enum(source,index)`. | Size lies between minimum and maximum. Sequence preserves declared order. Set uses declared equality and duplicate policy. Invalid members reject the entire construction. | Member expressions: 0..n, declared order, no exits or bindings. Expression/type. | kind=sequence, elementType=Int, items=[], minimum=0, maximum=3, equality=integer equality, order=source. Result []. | Remove minimum. Finding `missing-required`, path minimum. Empty admission cannot be inferred. | T checks members/bounds. C checks equality and duplicate policy. |
| VAL-VARIANT: construct a tagged, optional, or nullable value | R `alternatives:Map<Name,Ref<Type>>[1..n]`, `tag:Name`, `payload:TypedValue`. C(optional-form) `noneTag:Name`. C(nullable-form) `nullTag:Name`. | Exactly one declared tag governs the payload type. Optional none uses Unit. Nullable null uses Null. Unknown and Absent remain model states. Unknown tags or wrong payloads reject. | Payload expression: exactly one, no exits, expression/type. | optional-form=true, nullable-form=false, alternatives={some:Int,none:Unit}, tag=none, payload=unit, noneTag=none. Result None(unit), not Absent. | Remove noneTag from this optional form. Finding `missing-required`, path noneTag. | T checks tag/payload and conditional tag bindings. P preserves profile null differences. |

For VAL-VARIANT, `optional-form:Bool` and `nullable-form:Bool` are required discriminants. Their false values disable the corresponding conditional slots.

Pair in the fixture declares exactly left and right, each required Int, no defaults, no empty values, and rejection of extras.

These definitions use T02 type forms. They do not infer a storage layout or claim machine arithmetic support.
